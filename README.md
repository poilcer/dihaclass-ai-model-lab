# 같은 요청, 세 모델의 실제 결과

이 자료는 디하클 AI 비교 칼럼용 소규모 실습입니다. 세 서비스의 현재 화면에서 Gemini 4 Argon, GPT-6.1 Sol Medium(Work), Claude Opus 5.5 중간을 확인하고, 각각 새 대화에 동일한 `common_prompt.txt`를 넣었습니다. 화면의 선택 모델을 확인했으며, 서비스 내부 라우팅까지 독립적으로 검증한 것은 아닙니다.

## 직접 열어 보는 파일

각 `argon`, `sol`, `opus` 폴더에는 다음 네 파일이 있습니다.

- `shorts.md`: 가상 모아컵의 여섯 구간 쇼츠 기획·대본. 실제 영상·TTS가 아니며 낭독 시간은 미측정입니다.
- `factcheck.csv`: 제공한 여섯 주장에 대한 자료 내부 검토. 외부 사실을 검색해 판정한 결과가 아닙니다.
- `costs.csv`: 제공한 가상 단가로 계산한 두 요금제×네 작업량. 실제 AI 서비스 가격표가 아닙니다.
- `demo.html`: 브라우저에서 직접 열어 볼 수 있는 웹 시각화·비용 계산기. 컵은 코드로 표현한 개념도이지 상품 사진이나 치수 검증된 제품 모델이 아닙니다.

`response_raw.md`는 서비스에서 복사한 원 응답이며, 위 네 파일은 해당 응답의 네 코드 블록을 순서대로 추출했습니다. 생성 원본은 수정하지 않았습니다. 검사에서 발견한 문제도 원본을 고쳐 숨기지 않고 별도로 기록합니다.

## 공통 입력과 정답

- `common_prompt.txt`: 세 모델에 보낸 공통 요청문·가상 상품 자료·평가 조건
- `expected_costs.csv`: Hermes가 Decimal로 계산한 비교용 정답
- `expected_factcheck.json`: 주어진 자료에서 확인 가능한 주장과 미확인 주장의 정답
- `QA_REPORT.md` 및 `qa_results.json`: 실제 실행 검사가 끝난 항목과 실패/미검증 항목. 이 파일이 없으면 실행 검증 완료로 보지 마세요.

## 해석할 때 주의할 점

한 번의 묶음 요청으로 생성한 사례일 뿐 전체 성능 순위가 아닙니다. 기본 사고 설정 및 서비스별 실행 환경이 같다고 보장하지 않습니다. 출력 길이를 생성 속도나 품질 점수로 해석하지 마세요. 세 모델 모두 첫 응답을 보존했으며 재생성·우수본 선별은 하지 않았습니다.

대본 표에 적힌 5초 구간은 실제 발화가 해당 시간 안에 끝난다는 증거가 아닙니다. 실제 녹음·영상 제작은 하지 않았습니다. 가상 상품 정보와 가상 업무 요금을 실제 상품·실제 제공사 가격·광고 효능으로 전용하면 안 됩니다.

공개 게시 전 검토용 자료입니다. 칼럼 공개 등록은 별도 승인 대상입니다.
